## 📊 Dataset Overview (`weather_data.csv`)

The dataset simulates multi-station weather logs across 5 Indian cities (**Mumbai, Delhi, Chennai, Bangalore, Kolkata**) across 4 major seasons (**Winter, Summer, Monsoon, Autumn**).

| Column | Type | Unit | Description |
|---|---|---|---|
| `Date` | String | YYYY-MM-DD | Timestamp of reading |
| `Location` | String | City Name | Measurement station (Mumbai, Delhi, Chennai, etc.) |
| `Temperature_C` | Float | °C | Recorded ambient temperature |
| `Rainfall_mm` | Float | mm | Precipitation in 24 hours |
| `Humidity_pct` | Float | % | Relative humidity percentage |
| `WindSpeed_kmh` | Float | km/h | Sustained wind velocity |
| `Season` | String | Categorical | Winter / Summer / Monsoon / Autumn |

## 🚀 How to Run the Project

### 1. Run Hadoop MapReduce (CO2 Requirement)

#### Method A: 1-Click Execution (Recommended)
Simply double-click [`run_hadoop_mapreduce.bat`](run_hadoop_mapreduce.bat) or run in your terminal:
```cmd
.\run_hadoop_mapreduce.bat
```
This script will:
1. Clean previous outputs.
2. Compile `WeatherAnalysis.java` with Hadoop libraries using Java 8 compatibility.
3. Package `WeatherAnalysis.jar`.
4. Run the MapReduce job inside the official **Apache Hadoop 3** Docker container.
5. Print the `part-r-00000` output directly to your screen.

#### Method B: Manual Step-by-Step Terminal Execution
```cmd
:: Clean old output
if exist mr_output rmdir /s /q mr_output

:: Compile
javac --release 8 -classpath "hadoop_libs\hadoop-common-3.3.6.jar;hadoop_libs\hadoop-mapreduce-client-core-3.3.6.jar" -d . WeatherAnalysis.java

:: Package JAR
jar -cvf WeatherAnalysis.jar WeatherAnalysis*.class

:: Run Hadoop Job
docker run --rm -v "%cd%:/workspace" -w /workspace apache/hadoop:3 hadoop jar WeatherAnalysis.jar WeatherAnalysis weather_data.csv ./mr_output

:: View Output
type mr_output\part-r-00000
```

---

### 2. Run Apache Spark Analysis
PySpark executes in-memory DataFrames to compute seasonal statistics, extreme events, regional differences, and correlation matrices:

```cmd
python spark_weather_analysis.py
```

### 3. Run Standalone Python Analysis
To view the exact same mathematical analysis without needing Docker or PySpark:

```

### 4. Run Apache Hive Queries
If running on a Hadoop cluster with Hive installed:

```

## 🔍 Key Findings & Output Summary

### 1. Seasonal Patterns
- **Monsoon**: Accounts for over **70%** of annual rainfall (Mumbai peak daily rain: **450 mm**).
- **Summer**: Delhi recorded the highest regional temperature (**46.5°C**).
- **Winter**: North India (Delhi) experiences sharp cold drops (**7.0°C**), while coastal cities remain mild (**23°C - 25°C**).

### 2. Extreme Weather Events Flagged
- **Extreme Heat (> 40°C)**: 5 events (all concentrated in Delhi in May/June).
- **Heavy Rain (> 200 mm)**: 24 days detected across Mumbai, Kolkata, and Chennai.
- **High Wind (> 25 km/h)**: 11 events (primarily during Mumbai coastal monsoon storms).

### 3. Parameter Correlations
- **Rainfall ↔ Humidity**: Strong positive correlation (**r = +0.76**) — rain dramatically elevates atmospheric humidity.
- **Temperature ↔ Humidity**: Moderate negative correlation (**r = -0.35**) — hot peak summer periods coincide with dry air.
- **Temperature ↔ Wind**: Positive correlation (**r = +0.56**) — intense heat drives localized convective thermal winds (Loo in North India).
